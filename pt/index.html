Como funciona

O GitHub Pages apresenta um arquivo JSON público. Um workflow do GitHub Actions pode consultar a API oficial por órgão, validar campos e publicar um novo snapshot. Não há banco MySQL, Flask ou Selenium em execução neste site: essas tecnologias permanecem no projeto backend original.

O pipeline utiliza um token privado da API CGU. Quando há uma coleta oficial, o painel apresenta somente a amostra parcial consultada; caso contrário, identifica claramente dados sintéticos de demonstração.

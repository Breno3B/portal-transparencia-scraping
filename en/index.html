How it works

GitHub Pages displays a public JSON snapshot. A GitHub Actions workflow can query the official per-agency API, validate fields and publish updated data. MySQL, Flask and Selenium are not running on this website; they remain in the original backend project.

Access to the official API requires a CGU token saved as a GitHub secret. Before the first successful validated run, the page displays synthetic demonstration values only.
